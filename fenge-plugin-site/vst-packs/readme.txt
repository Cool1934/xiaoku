========================================
疯歌自用 VST 插件包 · 使用说明
========================================

【包含插件】
- ReaEQ       均衡器（提亮/切低频）
- ReaComp     压缩器（压动态/防爆音）
- ReaLimit    限制器（最后一道保护）
- ReaVerbate  混响（房间/大厅）
- ReaDelay    延迟
- ReaGate     噪声门（屏蔽环境声）
- ReaFIR      频谱降噪

【安装步骤】
1. 解压本包所有文件到 D:\VSTPlugins
   （没有就自己建，路径不要有中文）

2. 打开疯歌音效平台

3. 系统设置 → VST插件路径 → 添加 D:\VSTPlugins

4. 点「扫描插件」

5. 扫完后，插件出现在列表，拖到效果链里用

【推荐效果链顺序】
麦克风输入
→ ReaGate（噪声门）
→ ReaEQ（均衡）
→ ReaComp（压缩）
→ 混响/延迟
→ ReaLimit（限制器）
→ 输出

【注意事项】
- 插件全部来自 Cockos（Reaper官方免费包），安全无捆绑
- 下载地址：https://www.reaper.fm/reaplugs/
